家庭餐桌计划

让一家人的饭，少一点临时慌张

家庭做饭最难的不是菜谱，而是要同时照顾时间、口味、营养、库存和每个人的小偏好。小厨子帮你把一周家庭餐桌拆成可执行的备餐、购物和烹饪计划。

一个家庭菜单，要照顾很多细节

孩子不爱吃青菜，老人希望软烂一点，大人下班后只有 40 分钟做饭。家庭厨房计划会把同一批食材拆出不同口感：胡萝卜一部分炖牛腩，一部分切丁做蛋炒饭；西兰花给孩子做奶香焗烤，给大人做蒜蓉清炒。

儿童友好口味温和，蔬菜藏进蛋饼、饭团和浓汤。
长辈友好少油少硬，炖煮蒸菜比例更高。
上班日友好提前备菜，回家 30-40 分钟开饭。
周末仪式感安排一道能一起参与的大菜或烘焙。

周末家庭餐桌样例

周六晚餐可以安排“番茄土豆炖牛腩 + 蒜蓉西兰花 + 紫菜蛋花汤”。牛腩提前焯水炖 60 分钟，土豆最后 20 分钟再下，保留形状；西兰花焯水后快炒，孩子那份可以少蒜多一点芝士碎。

  • 提前准备：周五晚切好洋葱、胡萝卜，牛腩分装冷藏。
  • 亲子任务：孩子负责洗番茄、撕紫菜、摆碗筷。
  • 老人份：牛腩多炖 15 分钟，汤汁少盐，土豆压软。
  • 第二天复用：剩牛腩汤加面条，就是周日午餐。

三步建立家庭厨房节奏

记录家人偏好谁不吃辣、谁要软烂、谁需要高蛋白，小厨子都会记住。
生成菜单和备餐表把复杂晚餐拆成“提前处理”和“当天完成”两部分。
整理购物清单按蔬菜、肉蛋奶、主食、调味品分组，买菜不漏项。

厨房也可以是家里的小项目

家庭做饭不是一个人的任务。小厨子会把步骤写得足够清楚，让家人可以分工：一个人处理主菜，一个人洗菜，一个人准备餐具。周末还可以安排亲子可参与的披萨、饭团、烤南瓜和水果酸奶杯。

本周家庭备餐提醒

周日先处理耐放食材：焯西兰花、腌鸡腿、煮鸡蛋、分装米饭。叶菜留到前两天购买，口感会更好。
