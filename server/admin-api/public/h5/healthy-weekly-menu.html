轻负担一周计划

把健康饮食，变成每天都能坚持的菜单

健康不是连续七天吃水煮菜。小厨子会帮你安排有主食、有蛋白质、有蔬菜，也有好味道的一周菜单，让上班日不狼狈，周末也能认真吃一顿。

适合谁

如果你经常早餐随便对付、午餐靠外卖、晚上又因为太饿吃过量，这份计划会很适合。它不是严格减脂餐，而是让每一餐更稳定：蛋白质够、蔬菜够、主食不过量，调味依然有满足感。

上班族可提前备菜，午餐不靠临时决定。
轻体重管理控制油盐，但保留真实饭菜口感。
家庭共享大人清爽，小孩也能接受。
运动日训练日提高蛋白和优质碳水。

一周菜单样例

  • 周一：番茄牛肉荞麦面 + 凉拌黄瓜，适合工作日快速回血。
  • 周二：香煎鸡胸藜麦碗 + 烤南瓜，蛋白质和碳水都稳。
  • 周三：虾仁豆腐蒸蛋 + 糙米饭，口感柔和，晚餐不累胃。
  • 周四：菌菇鸡腿饭 + 生菜沙拉，适合提前一晚腌制。
  • 周五：清炒时蔬 + 三文鱼土豆泥，给一周收个轻松尾。

三步生成你的专属周菜单

填写饮食偏好比如不吃香菜、少辣、想控油、每天早餐 10 分钟内。
设定购物频率一周买两次菜，或周末集中备菜，小厨子会按保鲜期安排顺序。
同步购物清单自动合并重复食材，鸡蛋、青菜、主食一眼看清。

让菜单真正落地的小细节

小厨子会尽量让食材复用：周一牛肉面剩下的番茄，周三可以进蒸蛋；烤南瓜多做一份，第二天能变成沙拉配菜。这样不但省钱，也减少“买了一堆健康食材最后坏掉”的挫败感。

营养搭配原则

每餐优先保证一掌心蛋白质、一拳主食、两拳蔬菜。需要减脂时先减少油和零食，不轻易砍掉正餐主食。
