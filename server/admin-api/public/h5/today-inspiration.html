今晚推荐：青椒鸡蛋豆腐盖饭

用时约 18 分钟。鸡蛋先炒出香气，青椒切丝快速断生，嫩豆腐用生抽和少量蚝油轻轻煨 3 分钟，最后盖在热米饭上。它比普通蛋炒饭更有汤汁，又不会像重油外卖那样负担重。

  • 主食：剩米饭 1 碗，微波或蒸锅回温。
  • 蛋白质：鸡蛋 2 个 + 嫩豆腐半盒，适合晚餐补充。
  • 蔬菜：青椒 1 个，也可替换成彩椒、菠菜或西葫芦。
  • 调味：生抽、蚝油、白胡椒，少盐也能有层次。
